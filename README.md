# MedCalc PWA (ROOT, merged)

Incluye:
- Buscador CIE-11 (ICD-11) con endpoint/token configurables
- Todas las calculadoras con badges de información
- ABL con categorías (adulto H/M, infante, neonato, prematuro) y fórmula con Hb
- Módulo AHA 2025 paramétrico (coloca coeficientes en `config/aha2025.json`)

## Publicación
1) Sube TODO a la **raíz** del repo.
2) Settings → Pages → Source: Deploy from branch, Branch: main, Folder: /** (root)**.
3) Abre la URL y Añadir a pantalla de inicio en iPhone.

## ICD-11
- En la sección “Buscador CIE-11”, abre “Configurar acceso”, pega tu **token Bearer** y confirma el **endpoint**.
